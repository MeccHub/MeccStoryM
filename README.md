- `meccstorym.html` (redirects to `index.html`)
- `pages/mastercraft-scrolls.html` (Mastercraft Scroll Breakeven)

- `assets/css/site.css` (shared standalone-page styles)
- `assets/js/site-nav.js` (shared standalone-page navbar)
- `pages/_template.html` (starter template for new pages)
- `Calc/MSMevents.json`
- `Calc/MSMprobabilities.json`
